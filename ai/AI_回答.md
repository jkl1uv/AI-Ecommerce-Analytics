'AI Analysis Prompts'
Prompt 1: 用户复购分析
问题：请分析电商用户复购率较低的可能原因，并设计需要进一步验证的数据分析方案。
AI辅助结果：
一.可能原因：
1. 用户购买频率较低，产品消费周期较长。
2. 缺少会员体系和用户召回机制。
3. 首次购买后的用户运营不足。
4. 商品类别可能影响复购行为。
二.进一步验证：
1.分析不同商品类别复购率
2.分析首次购买后的再次购买时间
3.对不同客户群体进行RFM分析

Prompt 2: 用户分群运营建议
问题：根据RFM用户分群结果，为不同客户群设计运营策略。
AI辅助结果：
1.VIP客户：提供会员权益，提高长期价值。
2.近期客户：推动第二次购买。
3.普通客户：通过优惠券提高购买频率。
4.流失风险客户：设计召回营销活动。

Prompt 3: 商品销售分析
问题：根据商品收入排名，如何提出商业建议？
AI辅助结果：
1.高收入品类：增加库存和营销投入。
2.高销量低客单价品类：考虑组合销售提高订单价值。
3.低表现品类：分析用户需求后优化资源投入。
