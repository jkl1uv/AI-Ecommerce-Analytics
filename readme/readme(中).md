AI电商数据分析
项目概述
本项目通过分析电商交易数据，探索销售表现、客户行为、商品表现以及客户价值分群。项目使用DuckDB、SQL、Python 和 Power BI搭建了一套完整的数据分析流程。通过数据建模、SQL分析以及交互式数据可视化，将原始交易数据转化为具有业务价值的分析结果，为企业经营决策提供数据支持。

技术栈
数据库：DuckDB
查询语言：SQL
编程语言：Python
数据可视化：Power BI
数据处理：CSV 数据 / 数据分析流程

业务分析问题
本项目主要解决以下业务问题：
1. 销售额随着时间如何变化？
2. 客户重复购买率是多少？
3. 哪些商品类别贡献了最高收入？
4. 哪些客户属于高价值客户？
5. 大促（黑色星期五）带来了多少增量，是靠什么换来的？
6. 哪些品类最依赖大促，备货应该向哪里倾斜？

SQL 数据分析
1. 销售表现分析
1）分析内容：
月度销售收入趋势，订单数量变化，平均订单金额（客单价）
2）业务价值：
用于识别销售增长趋势和整体收入表现。
3）帮助企业了解：
哪些月份销售增长，销售是否持续提升，客户平均消费水平变化

2. 客户复购分析
1）分析内容：
客户总数量，重复购买客户数量，客户复购率
2）业务价值：
用于分析客户留存情况和客户忠诚度。
3）帮助企业：
发现客户流失风险，制定会员营销策略，提升客户生命周期价值

3. 商品类别分析
1）分析内容：
商品类别收入排名，商品类别订单数量
2）业务价值：
识别高表现商品类别。
3）帮助企业：
找出主要收入来源，优化商品运营策略，提升产品组合效率

4. RFM 客户价值分析
实现 RFM 分析模型：
R（Recency）：最近一次购买时间
F（Frequency）：购买频率
M（Monetary）：消费金额
用于识别，高价值客户，忠诚客户，潜在流失客户
业务价值：
帮助企业进行精准客户运营和营销。
说明：该数据集 97.0% 的客户仅购买一次，F 维度无区分度，分群实际改为
R、M 二维四象限划分，详见 report/business_insights(中).md

5. 大促脉冲分析
分析内容：
以 2017 年黑色星期五（2017-11-24）为样本，量化大促对收入、单量、客单价、
品类结构与支付分期行为的影响
业务价值：
判断大促的增量来源，指导备货分配、预算编制与促销 KPI 设定
核心发现：
黑五当日收入为 11 月日均的 5.2 倍、单量为 5.4 倍，但客单价下降 4.1%，
增量来自低价订单，属「以量换价」型大促；家居、美妆、礼品类弹性达 3.7-4.0 倍
